3. TECH STACK SPECIFICATIONS
================================================================================

A. BACKEND:
- Runtime: .NET 8 (C# 12)
- Framework: ASP.NET Core Web API
- ORM: Entity Framework Core 8 (Code-First)
- Database Provider: Microsoft.EntityFrameworkCore.SqlServer
- Design / Tools: Microsoft.EntityFrameworkCore.Design
- Authentication: JWT Bearer (Token issued with role claims: Admin / Customer)
- Password Hashing: PBKDF2 with salt (RFC 2898)
- API Documentation: Swagger / OpenAPI with Bearer Authorization UI
- Static Files: `app.UseStaticFiles()` enabled for `wwwroot/uploads`
- CORS Policy: `AllowAngular` allows `localhost` and `127.0.0.1` on any port with credentials.

B. FRONTEND:
- Framework: Angular 18 (Standalone Components, Signals, new Control Flow @if / @for)
- Styling: Tailwind CSS v3 + Custom SCSS variables
- State Management: Angular Signals (signal, computed) for Cart, Orders, and Filters
- HTTP: Angular HttpClient with Functional Interceptors (authInterceptor)
- Icons: Lucide Angular & Inline SVG icons
- Direction / Language: RTL (dir="rtl") with Arabic typography (Cairo & Baloo Bhaijaan 2)

C. DATABASE:
- Engine: Microsoft SQL Server 2019/2022 or LocalDB / Azure SQL
- Migrations: EF Core Migrations located in `SouqSofra.Infrastructure/Migrations`
- Automatic Startup Seed: Handled by `DbInitializer.InitializeAsync()` in `Program.cs`
  * Auto-applies migrations
  * Seeds Site Settings (phone, whatsapp, delivery fees, brand names)
  * Seeds Primary Branch (الكورنيش - أبوظبي)
  * Seeds Default Admin user:
    - Email: admin@souqsofra.com
    - Password: Admin@123456
  * Seeds 15 Menu Categories & ~20 Initial Products with Variants

5. BACKEND API ENDPOINTS REFERENCE
================================================================================
Base URL: http://localhost:2811/api

A. Public Endpoints:
- GET  /api/categories               --> List active categories
- GET  /api/products                 --> List products (supports ?categoryId, ?featured, ?search)
- POST /api/orders                   --> Submit new customer order
- GET  /api/branches                 --> List active branches
- GET  /api/settings                 --> Retrieve public site settings dictionary

B. Authentication:
- POST /api/auth/login               --> Accepts { email, password }, returns JWT token + user info

C. Protected Admin Endpoints [Authorize(Roles = "Admin")]:
- GET    /api/products/admin/all     --> List all products including hidden items
- GET    /api/products/{id}          --> Get single product details
- POST   /api/products               --> Create product
- PUT    /api/products/{id}          --> Update product
- PATCH  /api/products/{id}/availability -> Toggle product active state
- DELETE /api/products/{id}          --> Delete product
- POST   /api/categories             --> Create category
- PUT    /api/categories/{id}        --> Update category
- DELETE /api/categories/{id}        --> Delete category
- GET    /api/orders                 --> List orders for dashboard
- GET    /api/orders/{id}            --> Get detailed order items and customer info
- PATCH  /api/orders/{id}/status     --> Update status (Pending, Preparing, OutForDelivery, Completed)
- DELETE /api/orders/{id}            --> Delete order
- PUT    /api/settings               --> Update key-value setting (SettingKey, SettingValue)
- POST   /api/branches               --> Add new branch
- POST   /api/upload                 --> Upload image file (multipart/form-data)
                                         Query param: ?folder=products|banners|categories|logo
                                         Saves file to: `wwwroot/uploads/{folder}/`
                                         Returns relative `/uploads/...` and absolute `fullUrl`

7. HOW TO RUN THE PROJECT LOCALLY
================================================================================

PREREQUISITES:
- .NET 8 SDK
- Node.js (v18 or v20 LTS) & npm
- SQL Server (Developer edition, Express, or LocalDB)

STEP 1: DATABASE CONNECTION
- Open `Backend/SouqSofra.API/appsettings.json`
- Set `ConnectionStrings:DefaultConnection` to your SQL Server instance, e.g.:
  "Server=.;Database=SouqSofraDb;Trusted_Connection=True;TrustServerCertificate=True;"

STEP 2: RUN THE BACKEND (.NET 8)
- In terminal:
    cd Backend/SouqSofra.API
    dotnet restore
    dotnet run --launch-profile http
- The API will start on: http://localhost:2811
- Swagger UI will be available at: http://localhost:2811/swagger
- On startup, `DbInitializer` will automatically create tables and seed default data.
- (Alternative EF CLI Migration command):
    dotnet ef database update --project ../SouqSofra.Infrastructure --startup-project .

STEP 3: RUN THE FRONTEND (ANGULAR 18)
- In terminal:
    cd Frontend
    npm install
    npm start
- The Angular app will run on: http://localhost:4200
- Open browser at: http://localhost:4200
- Admin login is at: http://localhost:4200/admin/login
